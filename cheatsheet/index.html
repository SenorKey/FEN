Unit 0 Running Java

Program structure

Program skeleton

// file must be named Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println(25);
    }
}

Runs from main. println adds a new line. Statements end in ;

Run a file

java projects/Main.java

In the terminal. Compiles and runs in one step.

Comment

// Java ignores the rest of the line

Output

print vs println

System.out.print("a");    // no new line
System.out.println("b");  // new line after
System.out.println();     // just a new line

+ with text

"x = " + 3 + 4     // "x = 34"  left to right
"x = " + (3 + 4)   // "x = 7"   math first
3 + 4 + " total"   // "7 total"

Once one side is text, + joins instead of adding.

Compile errors

Reading a compile error

Main.java:4: error: ';' expected
        System.out.println(9)
                             ^

File:line, what Java wanted, ^ where it noticed. Fix the first one first.

Common compile errors

';' expected              missing ;
')' expected              missing )
unclosed string literal   missing "
reached end of file       missing }
cannot find symbol        typo in a name
package x does not exist  typo in System

Fixing one round of errors can reveal the next round.

Unit 1 Values & arithmetic

Variables

int variable

int a = 7;      // declare + assign (type once)
a = 12;         // reassign (no type)
a = a + 1;      // right side first: a is now 13
int c;          // declare only; assign before use

= is assignment: evaluate the right side, then store it in the left.

Arithmetic

Integer division and %

17 / 5     // 3   truncates toward zero
-17 / 5    // -3
17 % 5     // 2   remainder
-17 % 5    // -2  sign of the left operand
(a / b) * b + a % b == a   // always true
1 / 0      // ArithmeticException at run time

double and mixed arithmetic

double d = 2.5;
7 / 2          // 3    int / int
7 / 2.0        // 3.5  int promoted to double
double w = 7 / 2;   // 3.0  divides first, then widens
0.1 + 0.2      // 0.30000000000000004

Casting

(double) a / b      // cast a, then divide: exact
(double) (a / b)    // divide (truncates), then cast
(int) 6.67          // 6   truncates toward zero
int n = 3.5;        // error: possible lossy conversion

int → double is implicit; double → int needs a cast.
